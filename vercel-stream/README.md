# Vercel front for the File to Link bot

1. Replace YOUR-RENDER-APP in vercel.json with your Render service name.
2. Deploy this folder to Vercel (vercel CLI or import from GitHub).
3. On Render, set URL=https://YOUR-VERCEL-APP.vercel.app/ (trailing slash) and redeploy.
4. New links will now use the Vercel domain and be proxied to Render.
